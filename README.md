# 课间 · 课程表查询

《互联网软件开发技术与实践》第一课小项目。使用 AI 辅助开发，原生 HTML、CSS、JavaScript 实现，无第三方依赖。

## 使用

直接双击 `dist/index.html` 即可使用，也可以安装 Node.js 后在项目目录运行 `npm start`，打开终端给出的本地地址。

## 功能

- 整周课表和单日课程查询。
- 按课程、教师、教室关键词查询，支持教师筛选。
- 添加课程；校验必填项、节次范围及同日时间冲突。
- 查看课程详情，二次确认后删除。
- 数据保存在当前浏览器的 localStorage，刷新后保留。不同浏览器或访问地址的数据不会同步，清理浏览器数据会清除课表。
- 初次打开带有虚构演示数据，不代表真实课程安排；不接入真实用户资料、密钥或生产系统。

## 文件

- `dist/index.html`：页面
- `dist/styles.css`：响应式样式
- `dist/model.js`：查询、校验与示例数据
- `dist/app.js`：交互与本地保存
- `server.cjs`：可选本地预览服务器
- `test.cjs`：核心查询与冲突检查

运行 `npm test` 验证查询和冲突校验逻辑。
